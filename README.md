# MeuCandidato
Este é um site que indexa resultados de busca, curadorias e apis oficiais para gerar relatórios sobre candidatos à eleições no Brasil.

O cenário político do Brasil está envolto de corrupção e intransparência. A desinformação é pública e mais rápida que a informação. Para piorar, quem deveria cuidar do nosso país acaba não fazendo isso. Por conta disso eu iniciei este projeto com objetivo de utilizar diversas fontes para trazer à realidade daquele candidato que você se questiona se é bom ou não. 

A ideia é utilizar 4 principais fatores, sendo eles completamente filtráveis.

1. Dados cadastrais, patrimônio e situação eleitoral
2. Condenações por corrupção / improbidade administrativa ("ficha suja")
3. Histórico de mandato e processos em tribunais superiores e processos criminais / antecedentes
4. Grau de instrução (escolaridade)
